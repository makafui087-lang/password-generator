
# 🔐 Password Generator

A simple, secure password generator built with HTML, CSS, and JavaScript.

## ✨ Features
- Generate strong random passwords
- Choose password length
- Include uppercase, lowercase, numbers & symbols
- Copy password with one click

## 🚀 Live Demo
👉 https://makafui087-lang.github.io/password-generator/

## 🛠️ Built With
- HTML
- CSS
- JavaScript

## 📸 How to Use
1. Choose your password length
2. Select what to include
3. Click Generate
4. Click Copy
